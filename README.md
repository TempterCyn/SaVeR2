# SAVeR²: Reasoning-based Safety Alignment for Large Reasoning Models via Verifiable Rewards

Yichen Sun, Jianan Lin, Linbo Jiang, Shiyu Wang, Zhibo Wang, Zhixuan Chu

---

## Introduction

This is the official repository for our paper **"SAVeR²: Reasoning-based Safety Alignment for Large Reasoning Models via Verifiable Rewards"**, accepted to **NeurIPS 2026**.

SAVeR² is a safety-alignment framework for large reasoning models that addresses safety in both intermediate reasoning traces and final answers while preserving general reasoning capabilities.
